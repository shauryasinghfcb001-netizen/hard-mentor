## New hackathon work and pre-existing components

New work in this repository includes the study conversation/intake, topic priority and mastery updates, planner/checker/why-card loop, cited chapter quiz and score/progress flow, per-student H-MEM wrapper and controls, Zetaris and runtime adapters, fictional consent/deletion safeguards and local evaluation tooling. These are implementation claims grounded in [source](reviewer-guide.md); they are not a claim that every feature passed live acceptance. The Oct 27 packaging batch added documentation/evidence. The later Oct 28 browser build added the loopback launcher/server/browser, shared conversation setup and HTTP test. All were local and uncommitted at this release check.

The repository was built on the Meterless Agentathon Research Notebook starter. The starter notebook, engine loading pattern and H-MEM reference are pre-existing components. The vendored H-MEM implementation is downloaded during setup and is excluded from the proposed packaging asset list. The [conformance source manifest](../../vendor/hmem-conformance/SOURCE.json) records external source paths, commit and SHA-256 hashes.

**Mentor AI is a separate pre-existing product.** It is not Personalised Mentor's hosted demo. The local [adapter seam](../../src/integrations/mentorAI.ts) and optional memory wiring do not establish a deployed platform or overlay integration; adapter memory is off by default. Its external source was not inspected during this batch, and its external integration tests were excluded.

LangGraph, LangChain core, Zod, tsx, TypeScript and Node types are external dependencies. Locked npm metadata declares MIT for LangGraph, LangChain core, Zod and tsx, and Apache-2.0 for TypeScript. Actual installed MIT license texts were inspected for these direct dependencies, including `@types/node`; TypeScript has Apache-2.0 text plus `ThirdPartyNoticeText.txt`. Transitive installed package metadata also declares MIT, but license files were absent locally for `@cfworker/json-schema`, `@esbuild/darwin-arm64` and `js-tiktoken`; optional packages absent from this platform were not text-audited. This is an incomplete license audit. The project and local H-MEM package declare Apache-2.0, but no project top-level LICENSE/NOTICE or license-like file anywhere in the local H-MEM copy was found. The GitHub connector retrieved the complete tree at the actual pin and read its [root LICENSE](https://github.com/Meterless/Meterless/blob/1742dec56a66e58eef9dda2d2b865823758ca8cd/LICENSE): Apache-2.0, Copyright 2026 Meterless. `engines/hmem/LICENSE` has the identical Git blob. The exact text is preserved in [the upstream license asset](licenses/meterless-apache-2.0.txt); it does not invent a license for project-owned additions. The tree has no separate NOTICE outside bundled dependency directories. The earlier backup-branch 404 did not establish absence. Setup copies `engines/hmem/reference` and therefore omits the parent engine license. Owner review must preserve applicable notices/license text and identify modified upstream files. Preserve upstream attribution and have the owner verify applicable license text/notices before publication; no rights-clearance certificate is claimed.

## Data and reference material

[The corpus metadata](../../corpus/ncert-phy12-ch1.json) says its 14 chapter-1 notes were paraphrased on Oct 23, 2026 by Claude Code from [NCERT Physics Part I, Class 12, chapter 1](https://ncert.nic.in/textbook/pdf/leph101.pdf), Reprint 2026–27. It explicitly distinguishes them from earlier Lyzr chunks. Section and printed-page references are stored with each note. These are repository assertions; this packaging batch did not independently recheck the textbook, edition, page mapping or reuse permission. The notes, seed data, notebook/starter and H-MEM were prepared before the later browser build window; repository-described new hackathon work does not make them new browser-build work. Authorship and preparation dates do not grant external permissions. Attribution alone does not establish permission, and no claim is made that all third-party rights are cleared.

The seed topic weights, students, scores, answers and exam dates are synthetic. Mock exam research is labeled unverified; none of its dates or weightage should be read as official exam guidance. The demonstrated corpus covers one chapter, not every exam or all subjects. Evaluation and distress checks are synthetic engineering evidence, not independent learning-outcome or clinical validation.
